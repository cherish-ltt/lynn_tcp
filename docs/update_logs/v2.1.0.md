# v2.1.0 变更日志

发布日期：2026-09-17

## 概述

本版本以工程质量和协议解析稳定性为核心：新增更完整的静态扫描与密钥泄露检查钩子，修正协议字节解析、基准启动错误处理和状态注入内部类型结构，并同步更新锁定依赖。

本次变更保持公共 TCP 服务端与客户端 API 兼容；`with_server_single_processs_permit` 是拼写错误的内部命名修正，仅影响内部方法调用。

## 主要变更

### 1. build — 静态扫描与质量门禁

- 新增 `pre-commit-hooks`、`typos`、`ast-grep-rules`、`betterleaks` 以及本地 `cargo fmt` / `cargo check` / `cargo clippy` / `cargo test` 钩子。
- 提交阶段的测试钩子使用 `cargo test --tests --all-features`，避免长时基准阻塞普通提交；完整 `cargo test --all-targets` 仍可在发布或专项验证时执行。
- 为保留的 Clippy 抑制补充原因说明，规范章节注释，并新增 `.typos.toml` 豁免 `wrk` 工具名。
- 涉及文件：`.pre-commit-config.yaml`、`.typos.toml`、`src/lib.rs`、`src/infrastructure/tcp/reactor.rs`、README 与 README_ZH。

### 2. refactor — 协议与内部结构

- 协议解析改用固定长度切片，避免逐索引重建 `[u8; N]`；短报文错误路径补充边界测试。
- `StateRegistry`、`LynnRouter` 和 `FunctionSystem` 改为 tuple newtype，收窄内部表示；`AppStateParamState` 使用 tuple 形式承载 `PhantomData`。
- 基准 echo server 启动改为显式 `Result` 错误处理，不再使用 panic fallback；子进程 stdout、握手与地址解析错误都会返回明确信息。
- 涉及文件：`src/infrastructure/protocol/big_buf_reader.rs`、`src/infrastructure/validation/validation.rs`、`src/domain/state/*`、`src/domain/routing/router.rs`、`src/domain/handler/*`、`benches/benchmark.rs`。

### 3. fix — 拼写与日志文案

- 修正 `Excute` / `processs` / `sucess` / `Clinet` 等拼写错误，并同步公共配置表与版本历史。
- 更新 reactor 事件、服务端 permit、客户端心跳与日志初始化相关调用。
- 涉及文件：`src/infrastructure/tcp/reactor.rs`、`src/application/server/*`、`src/application/client/*`、README、README_ZH、`docs/version.md`。

### 4. build — 版本与依赖

- crate 版本升级至 `2.1.0`。
- 锁定依赖更新：`crossbeam-deque` `0.8.7` → `0.8.8`，`rustls` `0.23.43` → `0.23.45`，`sea-orm` `2.0.2` → `2.0.3`。
- 涉及文件：`Cargo.toml`、`Cargo.lock`。

## 向后兼容性

- 默认公共 API 保持兼容；`v2.0.0` 的服务端、客户端、TLS、重连和状态注入用法无需调整。
- 内部类型与拼写错误的内部方法名有调整；仅直接依赖 crate 内部路径的项目需要同步。

## 升级指南

1. 将依赖版本更新为 `lynn_tcp = "2.1.0"`。
2. 若直接引用内部配置或状态类型，检查 `get_server_single_process_permit` 等修正后的命名。
3. 执行 `cargo fmt --all -- --check`、`cargo clippy --all-targets -- -D warnings` 和测试验证。
