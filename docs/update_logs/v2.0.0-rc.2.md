# v2.0.0-rc.2 变更日志

发布日期：2026-09-05

## 概述

v2.0.0-rc.2 是发布候选的第二版，重点在于**工程化规范落地与质量保障**：引入 `AGENTS.md` 开发宪法、按规范重构 CI 与工具链配置、全面补齐测试（覆盖率从 19.65% 提升至 **91.91%**），并在测试驱动下修复了一个自定义协议标记的真实缺陷。

本版本**不改变任何公共 API**，对使用默认配置的用户完全透明。

## 主要变更

### 1. fix — 自定义消息标记响应帧缺陷

**文件**：`src/application/server/server_common.rs`

`check_handler_result` 中响应帧在 `set_marks` 之前就被 `get_response_data` 编码，导致配置了自定义消息头/尾标记（`with_message_header_mark` / `with_message_tail_mark`）的服务器，其**响应帧始终使用默认标记（9177/7719）**，自定义标记的客户端无法解析响应。使用默认标记的服务器不受影响（纯属默认值巧合）。

修复方式：先应用标记，再编码响应帧（与客户端发送路径的既有顺序一致）。

### 2. test — 测试覆盖率 19.65% → 91.91%

- 新增端到端集成测试（真实 TCP 链路，`tests/`）：
  - `server_client_integration.rs`：15 个用例，覆盖 echo 往返、多种 Handler 签名（0/1/2 参数及顺序）、广播、无响应 Handler、未知 method_id、未知 constructor_id、无效目标地址、零并发许可、每 IP 连接上限、全局最大连接数、客户端心跳保活、未启动/拒连的客户端错误路径。
  - `custom_protocol_marks.rs`：自定义标记端到端回归用例（验证上述 fix）。
- 新增单元测试：HandlerResult 帧编码布局、InputBufVO 顺序解析与防御性返回、LynnRouter 注册/覆盖/并发、错误类型与 `ToLynnError`、Server/Client Config Builder 全字段、BigBufReader 分帧/半包/粘包/非法头/超长消息防御、消息格式校验与 SafeBuffer。
- `cargo llvm-cov` 行覆盖率 **91.91%**（要求 ≥ 80%）。

### 3. build / ci — 开发规范（AGENTS.md）落地

- 新增 `AGENTS.md`：提交规范、CI 标准、格式化与 lint 规则、版本发布流程、文档同步要求。
- `rust-ci.yml`：按 AGENTS 标准更新（路径过滤触发、并发取消、锁定工具链 1.98.1、`clippy --all-targets -- -D warnings`）。
- 新增 `.rustfmt.toml`（`max_width=100`、`match_block_trailing_comma` 等）与 `.clippy.toml`（复杂度/参数/行数阈值、`msrv = "1.98.1"`）。
- `Cargo.toml`：依赖按用途分组注释，全部依赖以 `=` 锁定精确版本；新增 `[profile.dev]` 编译优化。
- 新增 `release.yml`：推送 tag 时自动从 `docs/update_logs/` 读取对应 md 内容发布 GitHub Release（与 `cargo-publish.yml` 并行触发）。
- `.gitignore` 扩充（IDE、macOS、AI 工具本地产物等）。

### 4. docs — 文档结构重组

- 新建 `docs/` 目录：`update_logs/`、`version.md`、`FlowChart.png`、`FlowChart-v2.png`、`monitoring/`（Grafana Dashboard 与 Prometheus 抓取配置迁入此处）。

## 向后兼容性

- ✅ **公共 API 签名不变**（`LynnServer`、`LynnClient`、`HandlerResult`、`InputBufVO` 等）。
- ✅ **默认配置行为不变**（默认标记下响应帧编码结果与 rc.1 完全一致）。
- ⚠️ **自定义标记服务器**：响应帧标记从"错误的默认值"修正为"配置值"——这是缺陷修复；若此前有客户端依赖了错误行为（以默认标记解析响应），需同步使用正确的自定义标记。
- ⚠️ 仓库文件位置调整：`update_logs/`、`version.md`、`FlowChart.png`、`grafana/`、`prometheus/` 迁移至 `docs/` 下（仅影响引用了仓库路径的文档链接）。

## 升级指南

### 从 v2.0.0-rc.1 升级到 v2.0.0-rc.2

大多数用户**无需修改任何代码**，只需更新版本号：

```toml
[dependencies]
lynn_tcp = "2.0.0-rc.2"
```

使用自定义消息标记的服务器：确认客户端使用了与服务器一致的自定义标记（此前的响应帧标记错误，正确行为现已恢复）。
