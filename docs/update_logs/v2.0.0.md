# v2.0.0 变更日志

发布日期：2026-05-21

## 概述

**v2.0.0 是 Lynn TCP 框架的一个里程碑版本**，从 v1.2.x 直接跳升至 v2.0.0，标志着项目架构从扁平单体演进为 **DDD（Domain-Driven Design）+ 洋葱架构（Onion Architecture）**。

本次重构在不改变任何公共 API 签名、不修改业务逻辑、不添加新功能的前提下，完成了代码结构的大规模重组，使得框架更加模块化、可测试、可扩展。

## 架构变更

### 旧架构（v1.2.x）

```
src/
├── app/            # 平铺的功能模块（服务器、TCP、连接管理）
├── handler/        # Handler 系统
├── client/         # 客户端逻辑
├── macros/         # 宏定义
├── dto_factory/    # 数据传输对象
├── vo_factory/     # 值对象
├── metrics.rs      # 指标收集
├── validation.rs   # 输入校验
└── ...
```

### 新架构（v2.0.0 — DDD + 洋葱架构）

```
src/
├── lib.rs                    # 接口层（公开 API 不变）
├── domain/                   # 领域层（纯业务逻辑，无基础设施依赖）
│   ├── model/                #   实体 + 值对象（HandlerResult, InputBufVO, LynnUser）
│   ├── routing/              #   路由抽象（LynnRouter）
│   └── handler/              #   Handler 系统（IHandler, SystemParam, ClientsContext）
├── application/              # 应用层（编排域对象与基础设施）
│   ├── server/               #   服务器应用服务（LynnServer, config, common）
│   └── client/               #   客户端应用服务（LynnClient, config, common）
├── infrastructure/           # 基础设施层（具体实现）
│   ├── tcp/                  #   TCP 网络（reactor, socket config）
│   ├── connection/           #   连接管理（limiter）
│   ├── protocol/             #   协议（big_buf_reader, message_codec）
│   ├── validation/           #   校验（validation）
│   ├── metrics/              #   指标（metrics, metrics_server）
│   └── macros/               #   宏（handler_macro）
├── const_config/             # 常量配置
└── error.rs                  # 错误类型
```

## 🎯 核心变更

### 2. 示例补充

新增 **7 个可运行示例**，覆盖所有框架使用场景：

| 示例 | 命令 | 用途 |
|------|------|------|
| `basic_server` | `cargo run --example basic_server` | 默认配置启动，展示 3 种 Handler 签名 |
| `custom_config_server` | `cargo run --example custom_config_server` | 通过 Builder 自定义服务器配置 |
| `custom_protocol` | `cargo run --example custom_protocol` | 自定义消息头尾标记 + InputBufVOTrait API |
| `echo_server_client` | `cargo run --example echo_server_client` | **完整请求-响应循环**（Client ↔ Server 双向通信） |
| `multi_route_service` | `cargo run --example multi_route_service` | **多路由分发验证** + 未知 Method ID 处理 |
| `custom_protocol_full` | `cargo run --example custom_protocol_full` | 自定义协议客户端配套（与 `custom_protocol` 配对） |
| `metrics_example` | `cargo run --example metrics_example --features metrics` | Prometheus 指标集成演示 |

## 向后兼容性

- ✅ **所有公共 API 签名不变**（`LynnServer`, `LynnClient`, `HandlerResult`, `InputBufVO` 等）
- ✅ **所有模块路径不变**（`lynn_server::*`, `lynn_client::*`, `lynn_tcp_dependents::*`）
- ✅ **所有 feature flags 不变**（`server`, `client`, `metrics`）
- ✅ **无行为变更**（纯结构重组，逻辑不变）
- ⚠️ **内部模块路径已变化**（不影响外部使用，仅影响内部开发者）

## 升级指南

### 从 v1.2.x 升级到 v2.0.0

对于大多数用户，**无需修改任何代码**。只需更新 `Cargo.toml` 中的版本号：

```toml
[dependencies]
lynn_tcp = "2"
```

如果使用自定义依赖版本：

```toml
[dependencies]
lynn_tcp = { version = "2", features = ["server", "client"] }
```

### 已知变化

1. Rust 编译器需要 `>= 1.95`（推荐使用最新 stable 版本）
2. 如果使用了内部模块路径（如 `use lynn_tcp::app::...`），需要更新——但这些路径在 v1.x 中也不是公开 API
