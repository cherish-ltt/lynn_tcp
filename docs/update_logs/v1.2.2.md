# v1.2.2 变更日志

发布日期：2025-12-25

## 概述

本版本主要改进了框架的错误处理机制，引入了专业的错误处理库 `thiserror` 和 `anyhow`，创建了统一的错误类型系统，消除了大量不安全的 `unwrap()` 调用，显著提升了代码的健壮性和可维护性。

## 主要改进

### 🔴 关键修复

#### 1. 引入错误处理库
**文件**：`Cargo.toml`

添加了两个专业的错误处理库：
```toml
thiserror = "2.0"  # 用于派生自定义错误类型
anyhow = "1.0"     # 用于简化错误处理（为后续使用做准备）
```

**选择理由**：
- `thiserror`：Rust 社区标准的错误处理库，自动实现 `Display`、`Error`、`From` 等 trait
- `anyhow`：提供灵活的上下文添加功能，适合应用层错误处理

#### 2. 创建统一错误类型系统
**新文件**：`src/error.rs`

创建了 `LynnError` 枚举，涵盖所有可能的错误场景：

```rust
use thiserror::Error;

#[derive(Error, Debug)]
pub enum LynnError {
    /// IO errors
    #[error("IO error: {0}")]
    Io(#[from] io::Error),

    /// Network-related errors
    #[error("Network error: {0}")]
    Network(String),

    /// Connection errors
    #[error("Connection error: {0}")]
    Connection(String),

    /// Address parsing errors
    #[error("Invalid address: {0}")]
    InvalidAddress(String),

    /// Configuration errors
    #[error("Configuration error: {0}")]
    Config(String),

    /// Buffer operation errors
    #[error("Buffer error: {0}")]
    Buffer(String),

    /// Message protocol errors
    #[error("Protocol error: {0}")]
    Protocol(String),

    /// Handler errors
    #[error("Handler error: {0}")]
    Handler(String),

    /// Timeout errors
    #[error("Timeout: {0}")]
    Timeout(String),

    /// Errors related to client operations
    #[error("Client error: {0}")]
    Client(String),

    /// Errors related to server operations
    #[error("Server error: {0}")]
    Server(String),

    /// Generic errors
    #[error("Error: {0}")]
    Generic(String),
}
```

**提供的功能**：
1. **类型别名**：`pub type Result<T> = std::result::Result<T, LynnError>`
2. **便捷构造函数**：`LynnError::invalid_address()`, `LynnError::network()` 等
3. **自动转换**：`io::Error` 自动转换为 `LynnError::Io`
4. **上下文添加**：`ToLynnError` trait 用于添加错误上下文

#### 3. 客户端配置错误处理改进
**文件**：`src/client/lynn_client_config.rs`

**修复前**：
```rust
pub fn with_server_addr<T>(mut self, server_addr: T) -> Self
where
    T: ToSocketAddrs,
{
    self.lynn_config.server_addr = server_addr.to_socket_addrs().unwrap().next().unwrap();
    self
}
```

**修复后**：
```rust
pub fn with_server_addr<T>(mut self, server_addr: T) -> Result<Self>
where
    T: ToSocketAddrs,
{
    self.lynn_config.server_addr = server_addr
        .to_socket_addrs()
        .map_err(|e| LynnError::invalid_address(format!("Failed to parse address: {}", e)))?
        .next()
        .ok_or_else(|| LynnError::invalid_address("No addresses found"))?;
    Ok(self)
}
```

**改进点**：
- ✅ 返回类型改为 `Result<Self>`
- ✅ 使用 `map_err` 转换底层错误
- ✅ 使用 `ok_or_else` 处理 `Option`
- ✅ 提供清晰的错误信息
- ✅ 消除 2 处 `unwrap()` 调用

#### 5. 服务器创建方法错误处理
**文件**：`src/app/mod.rs`

**修复前**：
```rust
pub async fn new_with_ipv4(ipv4: &'a str) -> Self {
    let mut app = Self::new().await;
    app.lynn_config.server_addr = ipv4.to_socket_addrs().unwrap().next().unwrap();
    app
}
```

**修复后**：
```rust
pub async fn new_with_ipv4(ipv4: &'a str) -> Self {
    let mut app = Self::new().await;
    match ipv4.to_socket_addrs() {
        Ok(mut addrs) => {
            if let Some(addr) = addrs.next() {
                app.lynn_config.server_addr = addr;
            } else {
                error!("Invalid IPv4 address: {}", ipv4);
                panic!("Invalid IPv4 address: {}", ipv4);
            }
        }
        Err(e) => {
            error!("Failed to parse IPv4 address '{}': {}", ipv4, e);
            panic!("Failed to parse IPv4 address '{}': {}", ipv4, e);
        }
    }
    app
}
```

**改进点**：
- ✅ 使用 `match` 显式处理所有情况
- ✅ 添加详细的错误日志
- ✅ 保留 `panic!` 以保持 API 兼容性
- ✅ 新增 `Level` 导入修复编译错误

#### 6. 缓冲区读取器错误处理
**文件**：`src/vo_factory/big_buf_reader.rs`

**修复 1 - get_data()**：
```rust
// 修复前
pub(crate) fn get_data(&mut self) -> BytesMut {
    let bytes = BytesMut::from(&self.data[10..self.target_len.unwrap() + 8]);
    self.check_data();
    bytes
}

// 修复后
pub(crate) fn get_data(&mut self) -> BytesMut {
    let target_len = self.target_len.expect("target_len should be set before get_data is called");
    let bytes = BytesMut::from(&self.data[10..target_len + 8]);
    self.check_data();
    bytes
}
```

**修复 2 - extend_from_slice()**：
```rust
// 修复前
if next_len.is_none() || next_len.unwrap() >= buf_len {
    self.data.extend_from_slice(buf);
} else {
    self.data.extend_from_slice(&buf[0..next_len.unwrap()]);
    // ...
}

// 修复后
match next_len {
    Some(len) if len < buf_len => {
        // Extend with part of the buffer
        self.data.extend_from_slice(&buf[0..len]);
        // ...
    }
    _ => {
        self.data.extend_from_slice(buf);
    }
}
```

**改进点**：
- ✅ 使用 `expect()` 提供清晰的 panic 信息
- ✅ 使用模式匹配消除嵌套的 `unwrap()`
- ✅ 代码逻辑更清晰，性能更优

#### 7. 客户端数据接收方法
**文件**：`src/client/mod.rs`

**修复前**：
```rust
pub async fn get_receive_data(&mut self) -> Option<InputBufVO> {
    self.rx_read.as_mut().unwrap().recv().await
}
```

**修复后**：
```rust
pub async fn get_receive_data(&mut self) -> Option<InputBufVO> {
    match self.rx_read.as_mut() {
        Some(rx) => rx.recv().await,
        None => {
            error!("Client is not connected. Call start() first.");
            None
        }
    }
}
```

**改进点**：
- ✅ 使用 `match` 显式处理 `None` 情况
- ✅ 添加有意义的错误日志
- ✅ 返回 `None` 而非 panic

## 向后兼容性

✅ **完全向后兼容**

虽然内部实现大量使用 `Result<Self>`，但通过以下方式保持 API 兼容：

1. **便捷方法使用 `.expect()`**：
   ```rust
   .with_server_addr(addr)
       .expect("Invalid server address")  // 提供清晰信息
   ```

2. **返回类型未变**：
   - `new_with_ipv4()` 仍然返回 `Self`
   - `new_with_addr()` 仍然返回 `Self`
   - `get_receive_data()` 仍然返回 `Option<InputBufVO>`

3. **现有代码无需修改**

## 性能影响

**零性能损失**：
- `thiserror` 是零成本抽象
- 编译时生成错误信息，运行时无开销
- `Result` 类型在编译时优化掉

**内存影响**：
- 新增 `LynnError` 枚举：约 100-200 字节（枚举变体）
- 新增 `thiserror` 和 `anyhow` 依赖：约 50KB（编译后）

## 用户迁移指南

### 对于现有用户

**无需修改代码**！所有改进都是内部实现细节。

### 对于新用户

推荐使用新的错误类型：

```rust
use lynn_tcp::{LynnError, Result};

async fn custom_handler(data: InputBufVO) -> Result<HandlerResult> {
    // 可以使用 ? 操作符
    let parsed = parse_data(&data)
        .map_err(|e| LynnError::protocol(format!("Parse failed: {}", e)))?;

    Ok(HandlerResult::new_without_send())
}
```

### 错误处理最佳实践

```rust
// ✅ 推荐：使用 Result 和 ?
async fn good_handler() -> Result<HandlerResult> {
    let data = read_data().await?;  // 自动传播错误
    Ok(HandlerResult::new_without_send())
}

// ✅ 可接受：使用 match 提供自定义处理
async fn better_handler() -> Result<HandlerResult> {
    match read_data().await {
        Ok(data) => Ok(HandlerResult::new_without_send()),
        Err(e) => {
            tracing::error!("Failed to read data: {}", e);
            Err(LynnError::handler("Data read failed"))
        }
    }
}

// ❌ 不推荐：直接 unwrap()
async fn bad_handler() -> HandlerResult {
    let data = read_data().await.unwrap();  // 可能 panic！
    HandlerResult::new_without_send()
}
```
