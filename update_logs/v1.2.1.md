# v1.2.1 变更日志

发布日期：2025-12-25

## 概述

本版本主要解决了代码中的关键安全问题，消除了不安全的裸指针使用，修复了内存泄漏风险，提升了代码质量和可维护性。

## 主要改进

### 🔴 关键修复

#### 1. 移除不安全的裸指针使用
**文件**：`src/app/router.rs`

**问题描述**：
- 原实现使用裸指针 `*mut HashMap<u16, Arc<AsyncFunc>>` 配合 `Box::into_raw` 进行手动内存管理
- 缺少 `Drop` trait 实现，导致严重的内存泄漏
- 使用 `unsafe` 代码块访问指针，存在内存安全风险
- 需要手动实现 `Send` 和 `Sync` trait

**修复方案**：
使用 `DashMap<u16, Arc<AsyncFunc>>` 替代裸指针实现

**修复前代码**：
```rust
pub(super) struct LynnRouter {
    pub(crate) map: *mut HashMap<u16, Arc<AsyncFunc>>,
    lock: Mutex<()>,
}

unsafe impl Send for LynnRouter {}
unsafe impl Sync for LynnRouter {}

impl LynnRouter {
    pub(super) fn new() -> Self {
        let map = HashMap::new();
        LynnRouter {
            map: Box::into_raw(Box::new(map)),
            lock: Mutex::new(()),
        }
    }

    pub(super) fn add_router<Param>(&self, method_id: u16, handler: impl IntoSystem<Param>) {
        if let Ok(_mutex) = self.lock.lock() {
            if let Some(map) = unsafe { self.map.as_mut() } {
                map.insert(method_id, Arc::new(Box::new(handler.to_system())));
            }
        }
    }

    pub(crate) fn get_handler_by_method_id(&self, method_id: &u16) -> Option<Arc<AsyncFunc>> {
        if let Some(map) = unsafe { self.map.as_ref() } {
            if map.contains_key(method_id) {
                return Some(map.get(method_id).unwrap().clone());
            }
        }
        None
    }
}
```

**修复后代码**：
```rust
pub(super) struct LynnRouter {
    pub(crate) map: DashMap<u16, Arc<AsyncFunc>>,
}

impl LynnRouter {
    pub(super) fn new() -> Self {
        LynnRouter {
            map: DashMap::new(),
        }
    }

    pub(super) fn add_router<Param>(&self, method_id: u16, handler: impl IntoSystem<Param>) {
        if self.map.contains_key(&method_id) {
            warn!(
                "Router - Duplicate method_id {} detected, existing handler will be overwritten",
                method_id
            );
        }
        self.map.insert(method_id, Arc::new(Box::new(handler.to_system())));
    }

    pub(crate) fn get_handler_by_method_id(&self, method_id: &u16) -> Option<Arc<AsyncFunc>> {
        self.map.get(method_id).map(|ref_| ref_.clone())
    }
}
```

**改进点**：
- ✅ 完全移除 `unsafe` 代码
- ✅ 自动内存管理，修复内存泄漏
- ✅ 删除 `unwrap()` 调用，使用 `Option::map()` 替代
- ✅ 移除显式的 `Mutex<()>` 锁，`DashMap` 内部处理并发
- ✅ 无需手动实现 `Send` 和 `Sync`
- ✅ 代码更简洁（40 行减少到 30 行）

#### 2. 消除 unwrap() 调用
**文件**：`src/app/router.rs:35`

原代码在 `get_handler_by_method_id` 方法中使用了 `unwrap()`，可能导致 panic。

**修复前**：
```rust
return Some(map.get(method_id).unwrap().clone());
```

**修复后**：
```rust
self.map.get(method_id).map(|ref_| ref_.clone())
```

### 🟢 新增功能

```rust

```

## 性能影响

**并发性能**：
- `DashMap` 采用分段锁（Sharding）技术，将数据分散到多个分片
- 对于读多写少的路由场景（启动时注册、运行时频繁查找），性能相当或优于原实现
- 支持真正的并发读操作，不会像单一 `Mutex` 那样阻塞所有读者

**内存使用**：
- 修复了内存泄漏问题，长期运行的内存占用会显著降低
- `DashMap` 有一定的额外内存开销用于分段管理，但影响可忽略
